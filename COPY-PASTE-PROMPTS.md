## Prompt 1 — Initial Codex Workspace Setup

Paste into **Codex**.

~~~text
I am a beginner. Set up this folder as a workspace for cinematic Instagram Reels.
1. Check existing project files. Do not delete or overwrite anything.
2. Create Assets, Audio, Output, and Project folders if missing.
3. Check whether Node.js, npm, FFmpeg, FFprobe, and a Remotion/Chromium rendering setup are available. Reuse
installed tools.
4. Explain anything missing in simple language. Ask before installing software or changing system settings. Use official
sources.
5. Check available video-production skills. Use suitable installed skills, and explain any additional skill installation before
proceeding. Do not assume a private skill exists on my computer.
6. Create a very short test animation and export a playable vertical MP4. Verify it works.
7. Use 1080x1920, 9:16, 30 fps, H.264 video and AAC audio.
8. Report what you created, what works, and the exact test video location. Do not generate paid narration yet.
~~~

## Prompt 2 — Reel Planning Using ChatGPT

Paste into **ChatGPT**.

~~~text
I want to make a cinematic Instagram Reel about [YOUR TOPIC] for [YOUR AUDIENCE]. Language: [LANGUAGE]. Target
length: [DURATION]. Use a premium, realistic visual style. First help me write a clear narration and a scene-by-scene
visual plan. Ask me to approve them. Then prepare one detailed prompt that I can paste into Codex to build the video.
Include scene visuals, camera movements, captions, narration timing, music guidance, sample review, and final export
settings. Avoid using private information or unlicensed media.
~~~

## Prompt 5 — Final Reel Production and Export

Paste into **Codex**.

~~~text
The narration and visual sample are approved. Complete the full Reel using the existing project.
Reuse approved scenes and audio. Do not rebuild working sections unnecessarily. Match scene durations to the actual
narration. Add readable captions, subtle music, and smooth transitions.
Export a separate review MP4 at 1080x1920, 30 fps, H.264/AAC. Keep editable sources. Check full video playback,
captions, audio balance, black frames, frozen sections, and mobile readability.
Target a practical completion time and report progress if rendering takes longer. Never sacrifice quality or claim
completion before the MP4 is verified. Do not post the video automatically.
~~~
